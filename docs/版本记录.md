# 版本记录

## Version 2.1.0 - PoA 演示重置与一致性加固 (2025-11-01)

### 🎯 版本概述
为演示环境提供一键重置能力，并修复提案在链上/数据库间可能出现的不一致问题，确保 PoA 版本始终保持可复现、零孤立数据的状态。

### ✅ 主要功能
- **演示重置脚本**：新增 `scripts/reset_poa_demo.sh`，自动备份数据库与合约文件并清空 PoA 数据目录，方便快速回到“干净”演示场景。
- **一键引导增强**：`bootstrap_poa_demo.py` 支持 `--force` 全量重建，并输出详细步骤日志。
- **一致性校验工具**：`scripts/validate_proposals.py` 可扫描提案是否仍存在于链上，`--fix` 选项能自动将缺失项标记为 `invalid`。
- **提案创建流程重构**：自动/手动创建提案时先确认链上交易成功，再写入数据库，杜绝新的孤立记录。
- **前端反馈优化**：`Proposals` 页面增加 `Invalid` 统计与醒目的告警面板，禁用对失效提案的签名操作。

### 🔧 技术细节
- `backend/app/services.py`：重写 `_create_auto_proposal`、`create_manual_proposal`，签名/拒绝前新增链上存在性检查，缺失则标记 `invalid` 并刷新缓存。
- `backend/main.py`：系统概览统计新增 `invalid` 计数，方便仪表盘展示。
- `frontend/src/components/ProposalCard.vue` & `frontend/src/views/Proposals.vue`：新增 `Invalid` 状态徽章、过滤器与提示文案。
- `docs/SYSTEM_OVERVIEW.md`：新增 PoA 运维工具章节，记录重置、引导、校验脚本的使用方式。

### 🐛 修复
- 修复提案签名时由于链上记录缺失导致的 `Proposal does not exist` 报错，界面现在会提示并自动将该提案标记为只读。
